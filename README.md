# 🐍 Nokia Snake

A web remake of the classic Snake game inspired by the old Nokia phone experience.

## Live Demo

**GitHub Pages:** https://lonelycoder2004.github.io/SNAKE-GAME/

## Features

- Classic monochrome LCD-style game screen
- Keyboard controls: Arrow keys or WASD
- Touch-friendly Nokia-style D-pad
- Score and browser-saved high score
- Pause and restart
- Increasing speed as the snake grows
- Retro sound effects using the Web Audio API
- Responsive phone-style interface
- Automatic GitHub Pages deployment with GitHub Actions

## Controls

| Action | Controls |
|---|---|
| Move | Arrow keys / WASD |
| Start | Space / START |
| Pause | P / Space |
| Restart | Space / START after game over |

## Run locally

Open `index.html` in a browser. No server or dependencies are required.

## Deployment

Every push to `main` is deployed to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.
